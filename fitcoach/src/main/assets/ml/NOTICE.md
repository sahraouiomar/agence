# Food classifier model

`food_v1.tflite` is Google's **AIY Vision Classifier Food V1** (MobileNet V1, 224×224 input, 2,023 dishes),
published on TensorFlow Hub / Kaggle Models under the **Apache License 2.0** (the licence is also embedded in the
model's TFLite metadata). Copy obtained from the public repository `second-state/wasm-learning`
(`faas/tflite_food/src/`), together with the label map `food_v1_labels.txt`.
